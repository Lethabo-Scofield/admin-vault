---
name: Focused project details
description: Rationale for focused project sections and on-demand supporting detail.
---

Keep project detail tasks separate, with summary information visible and long supporting lists expandable. Do not restore a single page that displays every usage list, key and document at once.

**Why:** The user described the stacked project detail page as messy and hard to understand. Separating tasks also avoids making key or document access wait for an unrelated external analytics database.

**How to apply:** Put additions in the relevant section and fetch only information needed for the selected section. Preserve server-side permission checks and reject unauthorized section selections rather than merely hiding their navigation.
