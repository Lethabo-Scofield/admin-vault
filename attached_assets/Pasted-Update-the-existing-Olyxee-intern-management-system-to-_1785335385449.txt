Update the existing Olyxee intern-management system to automatically generate internship certificates and recommendation letters.

I have uploaded two reference images:

2. Alisha-Fatima-AI-ML-Engineering-recommendation-letter.png

Use these files as visual references only. Do not use either image directly as the final background because they contain old names, dates, text and QR codes. Recreate both layouts as editable HTML/CSS templates so every intern receives accurate documents.

Preserve the existing intern-management system, authentication, database and current verification functionality. Inspect the project before implementing anything.

GOAL

From an existing intern profile, the super admin must be able to:

1. Enter or review the intern’s details.
2. Generate a public verification profile.
3. Generate a unique credential number.
4. Generate a secure verification URL.
5. Generate a new QR code containing that URL.
6. Preview an automatically generated certificate.
7. Preview an automatically generated recommendation letter.
8. Publish the credential.
9. Download both documents as PDFs.
10. Email both PDFs and the verification link to the intern.
11. Revoke the credential if necessary.

Do not use an LLM. This must use deterministic templates and database values.

Pronouns must be selected explicitly:

- THEY_THEM

Never infer pronouns from the intern’s name.

Use this mapping:

SHE_HER:
subject = she
object = her
possessive = her

HE_HIM:
subject = he

possessive = his

THEY_THEM:
subject = they
object = them
possessive = their

Add tests to prevent mixed pronouns such as:

“We wish her all the best in his future endeavours.”

CREDENTIAL GENERATION

Generate credential numbers in this format:

OLX-CERT-{YEAR}-{INTERN_NUMBER}-{SECURE_RANDOM_TOKEN}

Example:

OLX-CERT-2026-0002-Z2yBcQa1hK5S

Generate the token using a cryptographically secure random generator.

Create the verification URL:

https://www.olyxee.com/verify/{credentialNumber}

Example:

https://www.olyxee.com/verify/OLX-CERT-2026-0002-Z2yBcQa1hK5S

Generate a completely new QR code for every credential.

IMPORTANT QR REQUIREMENTS

- Do not reuse the QR code visible in the uploaded master certificate.
- Do not copy or preserve the old QR-code image.
- Generate the QR code dynamically from the final verification URL.
- Place the generated QR in the same approximate location shown in the certificate reference.
- Use a white background and sufficient quiet space around the QR code.
- Use high error correction.
- Test the generated QR by decoding it automatically.
- Confirm that the decoded value exactly matches the verification URL.
- The QR code must remain unchanged when documents are regenerated because the verification URL must remain permanent.
- If a credential is revoked, the QR still opens the same page, but the page must show REVOKED.

ADMIN WORKFLOW

Add these actions to the existing intern profile:

- Create credential
- Preview verification profile
- Preview certificate
- Preview recommendation letter
- Publish
- Download certificate
- Download recommendation letter
- Send by email
- Revoke credential

Workflow:

1. Super admin selects an intern.
2. System loads the intern’s stored details.
3. Super admin reviews dates, role, department, pronouns and recommendations.
4. Super admin clicks “Generate preview.”
5. System generates the credential number, permanent URL and QR code.
6. Show previews of the verification profile, certificate and recommendation letter.
7. Super admin corrects any problems.
8. Super admin clicks “Publish.”
9. Generate and store both final PDFs.
10. Activate the public verification page.
11. Enable email sending.

Do not publish or send anything automatically when an intern is created.
